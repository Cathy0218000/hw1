TAICHUNG TRAVEL GUIDE

漫步台中．探索城市之美

融合歷史古蹟、文創綠意與當代建築美學，精選四大不可錯過的台中經典景點。

歷史古蹟 / 特色冰淇淋

1. 宮原眼科

景點詳細介紹與特色

位於台中火車站附近的宮原眼科，是由 1920 年代日治時期的眼科診所歷史建築翻修而成。紅磚牆面與木造結構保留了濃厚懷舊風情，內部挑高設計更宛如魔法學院般的圖書室。這裡除了可以購買精緻的伴手禮，最受歡迎的就是多達數十種風味的手作特色冰淇淋！

文創聚落 / 甜點市集

2. 審計新村

景點詳細介紹與特色

由昔日臺灣省政府審計處的員工眷屬宿舍改建而成的老屋聚落。濃厚的懷舊建築風格吸引了眾多青年創作者進駐，隨處可見精緻風格咖啡廳、手做文創攤位與限定甜點小店。週末更有文創市集，是充滿人文活力的慢活景點。

城市綠洲 / 大人系公園

3. PARK2 草悟廣場

景點詳細介紹與特色

PARK2 草悟廣場結合了荒漠植物造景與當代建築概念，打造出一座專屬於大人的城市下沉式公園。這裡擁有豐富的大型塊根植物造景，並集結了個性餐廳、風格戶外選物店與特色酒吧，是感受陽光與綠意的絕佳落腳處。

世界建築美學 / 夕陽夜景

4. 臺中國家歌劇院

景點詳細介紹與特色

由日本知名建築師伊東豊雄設計，以「美聲涵洞」為概念，全館採用無樑柱的曲牆結構，被譽為世界新九大地標之一。內部空間充滿流線美感，開放民眾免費入館參觀展覽，頂樓更設有美麗的空中花園，傍晚時分能遠眺美麗夕陽與夜景。
